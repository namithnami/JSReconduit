## 📊 How to Use

1. **Start Burp Suite**  
   Make sure you have Burp Suite running and configured to capture traffic from your browser.

2. **Capture Traffic**  
   Use Burp Suite to capture the JavaScript traffic you are interested in analyzing.

3. **Import Traffic to JSReconduit**  
   Open JSReconduit and import the captured traffic from Burp Suite. The tool will convert the data into a structured format.

4. **Analyze Your Data**  
   Use JSReconduit to view and analyze the JavaScript information. The application provides various tools to visualize and inspect the data for security vulnerabilities.

## ❓ FAQs

### What is JSReconduit?

JSReconduit is a tool for penetration testers to conduct passive JavaScript reconnaissance by bridging Burp Suite traffic into structured analysis.

### Do I need programming skills to use JSReconduit?

No, JSReconduit is designed for users with no programming knowledge. The interface is simplified for easy navigation and usage.

### Can I use JSReconduit with any web application?

Yes, as long as you can capture the JavaScript traffic through Burp Suite, JSReconduit can analyze it.
